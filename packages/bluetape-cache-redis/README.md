# bluetape-cache-redis

English | [한국어](README.ko.md)

Opt-in Python 3.13+ Redis byte providers and bounded result-envelope contracts for bluetape-py.
The package keeps application serialization and compression policy caller-owned and is not part
of the default `bluetape` installation.

```bash
pip install "bluetape[cache-redis]"
```

The stable API includes structural payload/format contracts, immutable result envelopes, redacted
provider errors, and matching synchronous/asynchronous byte-provider operations. Complete usage and
operational guidance is added after the implementation is verified.
