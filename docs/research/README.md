## Update Rule

Update the matching research note before adding broad implementation issues or
changing milestone scope. Each note should name:

- source repositories and modules inspected;
- Python package direction;
- candidate dependencies and rejected alternatives;
- linked issues;
- current decision and non-goals.

Do not treat a research issue as implementation approval. Implementation starts
only after the package boundary, dependency policy, tests, and release impact are
clear.
