# 0.1.0 Foundation Lessons

## Context

Milestone `0.1.0` needed a thin Python-native foundation across `core`,
`logging`, `testing`, and release preparation without turning the meta
distribution into an import package.

## Decision

Keep each distribution independently minimal:

- `bluetape` is a meta distribution with no root import package.
- `bluetape-core` owns validation helpers.
- `bluetape-logging` is stdlib-only at runtime.
- `bluetape-testing` depends on `pytest` but not on `bluetape-core`.

## Outcome

The feature branch added focused contracts and tests for the first public helper
set, documented the package boundaries, and made CI build every workspace
distribution.

## Future Guidance

When adding a helper to a thin package, verify the package metadata as well as
imports. Extras may appear in `Requires-Dist`; smoke checks should separate base
requirements from extra-scoped requirements instead of expecting a one-line
metadata list.
