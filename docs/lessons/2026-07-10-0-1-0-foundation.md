# 0.1.0 Foundation 교훈

## 배경

Milestone `0.1.0`은 meta distribution을 import package로 바꾸지 않고 `core`, `logging`, `testing`, release preparation 전반에 얇은 Python-native foundation이 필요했습니다.

## 결정

각 distribution을 독립적으로 최소화합니다.

- `bluetape`는 root import package가 없는 meta distribution입니다.
- `bluetape-core`는 validation helper를 소유합니다.
- `bluetape-logging`은 runtime에서 표준 라이브러리만 사용합니다.
- `bluetape-testing`은 `pytest`에 의존하지만 `bluetape-core`에는 의존하지 않습니다.

## 결과

Feature branch에서 첫 public helper set을 위한 집중 contract와 test를 추가하고 package boundary를 문서화했으며 모든 workspace distribution을 build하도록 CI를 구성했습니다.

## 검증 근거

- `uv run pytest`: 21 passed
- `uv run ruff check .`: passed
- `uv run ruff format --check .`: passed
- `uv build --all-packages`: passed
- Import 및 package metadata smoke: passed

- `git diff --check`: passed

## 향후 지침

얇은 package에 helper를 추가할 때는 import뿐 아니라 package metadata도 검증합니다. Extra는 `Requires-Dist`에 나타날 수 있으므로 smoke check는 한 줄짜리 metadata list를 기대하지 말고 base requirement와 extra-scoped requirement를 분리해야 합니다.
